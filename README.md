# suorni-media

Radio Suornin somevideot (Instagram Reels / TikTok). Videot ovat julkisia, jotta julkaisutyökalu voi hakea ne.

- `videot/` – valmiit 1080×1920 -videot (metatiedot poistettu)
- `instagram-aikataulu.json` – Instagram-julkaisukalenteri. Ajastettu tehtävä julkaisee päivän Reelin klo 18 vain, jos rivillä on `"hyvaksytty": true`, ja merkitsee sen julkaistuksi.
